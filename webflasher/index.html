JUMA PA controller

Firmware installer · version …

Install

Connect the ESP32 by USB and click the button, then pick its serial port.

This browser has no Web Serial. Use Chrome or Edge on a desktop computer. Web Serial needs a secure connection (https).

On an update you can choose whether to erase the device. Without erasing, every setting stays, the update password included.

Requirements

  • An ESP32 with the classic chip and 4 MB flash, e.g. ESP32-WROOM / DevKitC. ESP32-S2, -S3, -C3 and -C6 do not work.
  • A MAX3232 level shifter between the ESP32 and the PA — see the wiring.
  • Chrome or Edge on a desktop computer.
  • If no port appears: the USB driver for the board's serial chip, CP210x or CH340.
  • If connecting fails, hold the BOOT button while it connects.

After installing

  1. Join the Wi-Fi JUMA-PA-XXXX, password juma-pa-setup.
  2. The dashboard usually opens by itself; otherwise go to http://192.168.4.1/.
  3. Enter your Wi-Fi and the TCI server under the gear icon and save.
  4. The device is then at http://juma-pa.local/.
  5. On its console (telnet juma-pa.local, or the installer's “Logs & console”):
    • otapass <new> — updates over the network stay locked until you do this
    • appass <new> — your own password for the fallback AP

Later updates go through the dashboard: juma-pa-…-firmware.bin from the latest release.
